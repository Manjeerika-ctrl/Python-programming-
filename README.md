Task 3 — Random Password Generator

A command-line tool that generates random passwords based on user-selected character types. It enforces a minimum length of 8 characters and guarantees that each selected character type is included.

Technologies: Python, "random", "string", loops, functions.

A command-line application that fetches current weather information for a specified city using the OpenWeatherMap API. It displays temperature, humidity, weather condition, and wind speed.

Technologies: Python, "requests", JSON, OpenWeatherMap API.
